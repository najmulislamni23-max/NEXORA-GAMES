NEXORA GAMES — AdMob Test Starter

এই ZIP-এ Android Studio project source code আছে, APK/AAB নেই।

যা আছে:
- NEXORA GAMES-এর ছোট নমুনা গেম
- Rewarded video ad integration
- Google-এর official SAMPLE AdMob App ID এবং Rewarded Ad Unit ID
- বিজ্ঞাপন দেখার পর শুধু ভার্চুয়াল কয়েন যোগ হয়

গুরুত্বপূর্ণ:
1. Test ad দিয়ে আয় হয় না। নিজের live AdMob ID বসানোর আগে AdMob account খুলে app register করতে হবে।
2. নিজের app ID ও ad unit ID ছাড়া live ad চালু হবে না।
3. Play Store-এ প্রকাশের আগে Google-এর বর্তমান SDK, privacy/consent, Data safety, content rating এবং Play policies পূরণ করতে হবে।
4. কখনো নিজের live বিজ্ঞাপনে নিজে ক্লিক করবেন না। Development-এ test ads ব্যবহার করুন।
5. এই প্রকল্পটি compile করে APK/AAB বানানো হয়নি।

প্রজেক্ট খুলতে Android Studio/সমর্থিত Android IDE এবং internet connection দরকার।
